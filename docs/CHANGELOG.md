# 版本演进摘要

此文件记录工程边界，详细报告留在对应发行产物中。日期采用 Asia/Shanghai。

## 0.7.0 · 2026-10-25

- 白色应用主题、轻量粉色卡片。
- 操控区四分类横向分页；下方独立睁闭眼按钮。
- 整个操控卡片右上角内凹，圆按钮与分类水平对齐；顶部表情按钮移除。
- 主页面固定高度，窄屏去掉整页横向/纵向溢出。
- 大肥鱼头像移除鳍耳装饰，按主头部取景，裁掉多余呆毛；不改变角色本体。
- 表情脸图 288×288，头像 384×384。

## 0.6.0 · 2026-10-25

- 初音与鲸鱼娘统一默认 GPU、预编译求值、帧通道。
- 原生屏幕 DPR 画布与高清矢量图块，移除旧低清降采样策略。
- 更紧凑的图集矩形打包，修正首次舞台尺寸带来的重复大纹理。
- 刘海冠部固定、下部渐进弯曲；左右前发和短下层发束继续重绘。
- 两种求值器数值、高清渲染、回退、角色切换与 CPU 限速测试。

## 0.5.1 · 2026-10-25

- 曾通过把整个头部移到前侧发束前方修复层级。
- 后续对照暴露出素材闭合边与耳部遮挡问题；现已撤回该整头置顶方式，使用完整轮廓与隐藏衔接处理。不要复制该历史修复。

## 0.5.0 · 2026-10-25

- 当前简化 Toy 入口替代制作室界面。
- 头像选角、菜单、真实脸部表情按钮；旧录制/时间轴等不再挂载。

## 0.4.0 · 2026-10-25

- 动画时钟与 React UI 解耦、骨架预编译、矩阵/缓冲复用。
- FPS 改为实际提交/commit，而非输入 RAF 计数。

## 更早阶段

鲸鱼娘分层母版、后发/布料二级运动、初版 GPU、SDK 适配与上传流程。
